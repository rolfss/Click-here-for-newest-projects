# Fjordsprint 3.2 – helhetlig grafikk og mobilhjelp

Boostfeltene er nå sammenhengende, avrundede flater som følger veiens kurver og høyde, med én tekstur og ett tegnekall per felt. De gamle overlappende klossene er fjernet fra scenen. Felles dempet fargepalett, mykere terrenglys, avrundede bilkanter, diffus bilskygge og mer enhetlige paneler. Ingen ekstern grafikkavhengighet eller tunge ettereffekter.

Mobil har egne kontroller og layout: analog tommelstyring med presisjonskurve, større knapper, automatisk gass, fartsdemping før svinger og automatisk vann mot troll i siktet. Spilleren må fortsatt styre. Automatisk vann kan slås av underveis. Mobilhjelp kan slås av i startmenyen for manuell kjøring. Spillknappene skjules når spørsmål eller pause vises. Flere samtidige fingre, avbrutt berøring og skjermrotasjon håndteres separat.

Med mobilhjelp står spørsmålene uten nedtelling, og spilleren velger selv når forklaringen skal lukkes. Egen rekordklasse for mobilhjelp; eksisterende manuelle tider beholdes. Navn før start og 48 timers lokal resultatlagring er uendret. Ingen server eller deling av navn mellom enheter.

Sykehuspartner-logo, 44 sykehus/behandlingssteder, alle tre baner, 54 spørsmål, kompetansekanon og karriererakett beholdes. Byggene er fortsatt stiliserte og løypene geografisk fiktive.

Tester: nye enhetstester for alle ni boostflater, presis tommelstyring, trygg automatisk brems, vannkanon og separat tidsbegrenset toppliste. Nettlesertestene kontrollerer også ekte samtidige touch-hendelser, avbrudd, spørsmål uten tidsfrist, knappenes treffområder og flere skjermstørrelser. Skjermbilder fra testene lagres som GitHub Actions-artefakter. Automatisk nettlesertesting er ikke det samme som testing på fysiske mobiler.
